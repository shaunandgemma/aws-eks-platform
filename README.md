I am going to build and operate a production-style container platform on AWS using Kubernetes

\## Skills I Want to Demonstrate



How to create a functioning Kubernetes service

Use Terraform as IaC

Run Helm as the Kubernetes package/deployment tool

Use Git and GitHub as the repository

Monitor with CloudWatch at a production level

Use a containerised system

Use least privilege IAM and secure access controls

Network all parts of the project to ensure proper communications

Auto-scale to ensure system stability and scaling

Troubleshoot failures using logs, metrics and Kubernetes and AWS diagnostics tools
